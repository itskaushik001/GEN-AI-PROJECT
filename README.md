# Gen AI Interview Prep Tool

A full-stack application built to help users practice interviews using Generative AI.

## 🚀 Features
- **Frontend**: Interactive UI built with React and Vite.
- **Backend**: Node.js and Express server with database integration.
- **AI Integration**: Powered by Google AI / GCP services.

## 🛠️ Tech Stack
- **Frontend**: React, Sass, Vite, ESLint
- **Backend**: Node.js, Express, Zod (Validation)

## 💻 Local Setup

### 1. Clone the Repository
```bash
git clone https://github.com
cd GEN-AI-PROJECT
```

### 2. Backend Setup
1. Navigate to the folder: `cd Backend`
2. Install dependencies: `npm install`
3. Create a `.env` file based on your environment needs and add your API keys:
   ```env
   PORT=5000
   GCP_API_KEY=your_secret_key_here
   ```
4. Start the server: `npm start` or `npm run dev`

### 3. Frontend Setup
1. Navigate to the folder: `cd ../Frontend`
2. Install dependencies: `npm install`
3. Start the application: `npm run dev`
